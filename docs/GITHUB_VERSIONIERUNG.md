# GitHub Versionierung

## Versioniert

- `docker-compose.yml`
- `.env.example`
- `README.md`
- `docs/`
- `custom/themes/`
- `custom/plugins/`
- `custom/snippets/`
- `scripts/`
- `.gitignore`

## Nicht versioniert

- WordPress-Core
- `wp-admin/`
- `wp-includes/`
- `wp-content/uploads/`
- Datenbankdaten und Dumps
- `.env`
- Passwörter, Tokens, SSH-Keys
- Logs, Backups, Cache, temporäre Dateien

## Hintergrund

GitHub ist die Steuerzentrale des Projekts, nicht das Archiv einer kompletten WordPress-Installation.
