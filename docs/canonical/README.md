# Canonical Docs

Diese Dokumente bilden die erste kuratierte Canonical-Docs-Basis fuer `webapp-central.de`.

Sie sind keine Blogbeitraege, sondern ruhige Referenztexte mit langfristigem Geltungsanspruch. Ihr Zweck ist es, Plattformidentitaet, Governance, Dokumentationslogik und Architekturprinzipien nachvollziehbar zu machen.

## Ziel der Canonical Docs

- Wissenskern der Plattform sichtbar machen
- Governance und Architektur als Referenz festhalten
- stabile Einstiegspunkte fuer neue Leser schaffen
- langfristig gueltige Dokumentation von Journal- und Timeline-Inhalten trennen

## Redaktionelles Muster

Alle Canonical Docs folgen demselben Grundraster:

- Kurzbeschreibung
- Metadaten
- Zweck
- Kontext
- Kernprinzipien
- Einordnung in die aktuelle Phase
- Strategische Ableitung
- Auswirkungen
- Anschlussfragen
- Verwandte Dokumente

Dieses Raster soll spaeter auch fuer die oeffentliche Dokumentationsdarstellung als ruhige Referenzlogik dienen.

## Vorlaeufige Ableitung fuer die spaetere Dokumentationsstruktur

Fuer den spaeteren WordPress- oder Web-Dokumentationsbereich laesst sich aus dem aktuellen Bestand eine bewusst kleine Grundstruktur ableiten:

1. Plattformgrundlagen
   - Warum webapp-central.de keine klassische Website ist
   - Grundprinzipien der Plattformarchitektur
2. Governance & Arbeitslogik
   - Einfuehrung der AGENTS.md
   - Dokumentation als Plattformgedaechtnis
3. Infrastrukturprinzipien
   - GitHub als Steuerzentrale statt WordPress-Archiv

Diese Struktur soll vorerst nicht aufgefaechert, sondern als ruhige Referenzbasis behandelt werden. Weitere Formate wie Journal, Timeline, ADR oder Leitfaden sollen spaeter bewusst davon getrennt werden.

## Abgrenzung

Canonical Docs beschreiben stabile Grundlagen. Zeitgebundene Entwicklungen, Migrationsschritte, Versuche und Fortschrittsberichte gehoeren spaeter in Journal-, Timeline- oder Entscheidungsformate.
